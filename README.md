# یادآور شمسی - Samsung Reminder Jalali Clone

اپلیکیشن پیشرفته یادآور شمسی برای اندروید با الهام دقیق از رابط کاربری One UI سامسونگ، همراه با تقویم کامل جلالی، ویجت تعاملی با ۳ سطح اندازه فونت، پردازش گفتار فارسی و پایپلاین اتوماتیک GitHub Actions برای خروجی گرفتن APK.

---

### ویژگی‌های کلیدی:
1. **معماری تمیز (Clean Architecture)**: تفکیک لایه‌های Domain، Data و Presentation به همراه الگوی BLoC.
2. **پایگاه داده محلی**: ذخیره‌سازی ماندگار با SQLite و بدون نیاز به اینترنت.
3. **تقویم شمسی (Jalali)**: با استفاده از پکیج `shamsi_date` برای گروه‌بندی‌های امروز، فردا، آینده و سررسید گذشته.
4. **ویجت هوماسکرین اندروید (Home Widget)**:
   - قابلیت تنظیم اندازه فونت در ۳ سطح (کوچک: ۱۲sp، متوسط: ۱۴sp، بزرگ: ۱۷sp) از طریق تنظیمات برنامه با اعمال فوری
   - قابلیت Expand/Collapse برای یادآورهای دارای زیرمجموعه
   - امکان تیک زدن کارها به صورت مستقیم از روی ویجت
5. **رفتار دقیق چک‌لیست**:
   - تیک زدن زیرمجموعه: فقط همان مورد خط می‌خورد و کم‌رنگ می‌شود.
   - تیک زدن یادآور اصلی: کل یادآور با انیمیشن محو شده و به بخش انجام‌شده‌ها منتقل می‌شود.
6. **ایجاد یادآور با صوت هوشمند (Voice NLP)**: استخراج خودکار عنوان، تاریخ شمسی و ساعت از گفتار فارسی.
7. **منوی تعویق (Snooze)**: ۵، ۱۵، ۳۰ دقیقه، ۱ و ۲ ساعت یا تاریخ دلخواه.
8. **پشتیبانی کامل از Android v2 Embedding**: بدون خطا در Flutter 3.19 تا 3.29+.

---

### مراحل ساخت خودکار APK در GitHub:
1. یک ریپازیتوری جدید در حساب گیت‌هاب خود ایجاد کنید.
2. فایل ZIP پروژه را دانلود کرده و محتویات آن را درون یک پوشه خالی Extract کنید.
3. با دستورات زیر پروژه را در گیت‌هاب بارگذاری نمایید:
```bash
git init
git add .
git commit -m "feat: complete shamsi reminder with v2 embedding"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/shamsi_reminder.git
git push -u origin main
```
4. وارد تب **Actions** در ریپازیتوری گیت‌هاب شوید.
5. اکشن **Build Android APK (Release)** به صورت اتوماتیک اجرا شده و پس از پایان، فایل‌های نهایی APK در بخش Artifacts آماده دانلود هستند!
